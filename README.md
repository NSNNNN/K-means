تشخیص داده‌های پرت با K-Means
توضیح پروژه

این پروژه یک روش ساده برای شناسایی داده‌های پرت (Outliers) با استفاده از الگوریتم K-Means را نشان می‌دهد.
در این روش:

داده‌ها با K-Means خوشه‌بندی می‌شوند.

فاصله هر نقطه تا مرکز خوشه خودش محاسبه می‌شود.

داده‌هایی که فاصله‌شان از میانگین فاصله‌ها بیشتر باشد، به عنوان داده پرت شناسایی می‌شوند.
