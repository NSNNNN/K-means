# پیدا کردن داده‌های پرت در K-Means

## توضیح

K-Means یک الگوریتم خوشه‌بندی (Clustering) است که داده‌ها را به **k** خوشه تقسیم می‌کند.  
داده‌هایی که فاصله زیادی با مرکز خوشه خود دارند، می‌توانند به عنوان **داده‌های پرت (Outliers)** در نظر گرفته شوند.

در این پروژه، چند روش متداول برای شناسایی داده‌های پرت با استفاده از K-Means بررسی شده است.

---

## روش‌های شناسایی داده‌های پرت در K-Means

### 1. استفاده از فاصله تا مرکز خوشه

- پس از اجرای K-Means، فاصله هر نمونه تا مرکز خوشه‌ی مربوط به خودش محاسبه می‌شود.  
- داده‌هایی که فاصله‌شان از مقدار  
  **میانگین + 2 انحراف معیار (μ + 2σ)**  
  یا  
  **میانگین + 3 انحراف معیار (μ + 3σ)**  
  بیشتر باشد، به عنوان داده‌ی پرت در نظر گرفته می‌شوند.

---

### 2. استفاده از Inertia یا SSE

- **SSE (Sum of Squared Errors)** مجموع مربعات فاصله‌ی نقاط از مراکز خوشه‌ها است.  
- داده‌هایی که سهم بزرگی از SSE را تشکیل می‌دهند، معمولاً داده‌های پرت محسوب می‌شوند.

---

### 3. استفاده از الگوریتم‌های هیبریدی

- برای دقت بیشتر می‌توان K-Means را با الگوریتم‌هایی مانند:
  - **Local Outlier Factor (LOF)**
  - **DBSCAN**
  
  ترکیب کرد تا داده‌های پرت با اطمینان بیشتری شناسایی شوند.
